# 💳 one-man-bank

> A dedicated cloud-based financial and wishlist management system tailored for love one, designed to easily manage funds, claim exclusive perks, and keep track of sweet moments anytime, anywhere! ✨

---

## 🌟 Features

- **👑 Dual-Role Interface**: Clear permission separation between the "love" dashboard and the "Admin" management backend.
- **📅 Monthly Check-in**: Automated monthly check-in mechanism to claim the monthly allowance fund with a single click.
- **💌 Monthly Wishlist Board**: A dedicated space for wishes and messages, allowing the admin to review and issue custom rewards flexibly.
- **🎟️ Exclusive Coupons**: Redeemable perk system (e.g., custom dinner, special favors) with complete usage history.
- **📜 Comprehensive Ledger**: Fully tracked logs covering transfers, check-ins, reward payouts, and expense deductions.

---

## 🛠️ Tech Stack

- **Frontend & UI**: [Streamlit](https://streamlit.io/) (Python Web Framework)
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL + Session Pooler)
- **Cloud Hosting**: Streamlit Community Cloud
- **Language**: Python 3.10+
